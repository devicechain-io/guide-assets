# guide-assets

Generated screenshots for the DeviceChain console user guide.

The documentation build consumes this repository at a pinned commit (recorded in the
DeviceChain repository as `docs/guide-assets.lock`) and fetches exactly that commit.

- Files are named `{id}.{locale}.webp`, described by `manifest.json`.
- Everything here is generated by the guide capture harness. Never hand-edit it.
- History is disposable and may be squashed at any time; only pinned commits matter to the docs.
